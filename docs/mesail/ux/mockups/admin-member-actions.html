MesailAdmin

Member actions in the admin app (SPEC AC-ID-12, AC-ID-13). Role and removal act on example.com only. Account actions (reset password, remove 2-step code, remove all passkeys, turn off, change name) act on the person's one account, so the server allows them only for an Operator or an admin of every domain of that person; otherwise it answers 403.

State 1 · Remove a member

Remove Eve Park from example.com?

  • Eve loses example.com within a minute.
  • Mail to eve@example.com is refused.
  • Her messages stay, with her name.
  • Her account, her password and her other domains do not change.
  • The username eve stays hers.
CancelRemove from example.com

State 2 · 409 last_admin on a role change

example.com needs an admin

Bo Lee is the last admin of example.com, so the role did not change. Make another member an admin first.

OK

State 3 · 409 last_admin on a removal

example.com needs an admin

Bo Lee is the last admin of example.com and cannot be removed. Make another member an admin first, then try again.

OK

State 4 · Reset a password (AC-ID-13 allowed: Dan is only in example.com)

Reset Dan Example’s password?

This is Dan’s one password for every domain. Dan is signed out everywhere and must choose a new password at the next sign-in.

CancelReset password

State 5 · Password reset done

Password reset

Dan is signed out everywhere. Dan signs in with the new first password and then chooses a new one.

Done

State 6 · 403 forbidden: the person is also in a domain the admin does not manage

You cannot change Eve Park’s account

Eve Park is also a member of a domain you do not manage. A change to her account would change her sign-in there too.

Ask the Operator of this Mesail install, or an admin of all of Eve’s domains.

OK

State 7 · Remove the 2-step code

Remove Dan Example’s 2-step code?

Use this when Dan lost the phone with the authenticator app. Dan then signs in with the password only, in every domain, and can set up 2-step sign-in again in Settings.

CancelRemove 2-step code

State 8 · Turn off an account

Turn off Dan Example’s account?

Dan is signed out within a minute and cannot sign in to any domain. Messages and the address dan@example.com stay. You can turn the account on again later.

CancelTurn off account

State 9 · Change a name

Change Dan Example’s name

CancelSave

State 10 · Remove all passkeys (AC-ID-13, AC-ID-18)

Remove all of Dan Example’s passkeys?

Use this when Dan lost a device with a passkey and cannot remove it. Dan can no longer sign in with Touch ID, Face ID, Windows Hello or any other passkey, on any device. Dan still signs in with the password and 2-step code, and can add new passkeys in Settings.

Dan will be signed out on every device, in every domain, within a minute. Devices that are signed out delete their copy of Dan’s messages.

CancelRemove all passkeys

State 11 · Passkeys removed (also when Dan had none; a 403 shows state 6)

Passkeys removed

Dan has no passkeys now and is signed out everywhere. Dan signs in with the password and 2-step code.

Done
