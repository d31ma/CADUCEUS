History rows (SPEC AC-CL-4, AC-CL-5; ADR 0012 decision 6). The caller’s device adds “Call started”, “Call ended” and “Missed call” as encrypted chat messages, so they sync and back up like messages; each device writes the words for its own person (“Missed call from Ana Ruiz” for Bo, “Bo Lee did not answer” for Ana). A declined call shows as missed. Rows are system rows, not messages: no reactions, no thread, no edit.
