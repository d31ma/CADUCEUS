Mesail

Recording (SPEC AC-CL-8; ADR 0012 decision 10; TACHYON P7). A recording is made only on the recorder’s own device, to a file they choose. Before it starts, every device in the call must have the notice; then everyone sees “Recording by <name>”, which has no close button while it runs, also for people who join later. The banner is a role="status" line: screen readers hear it once when it appears, and it stays in the call view’s reading order at the top.
