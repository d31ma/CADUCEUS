Mesail UX mockups

Static HTML built with DuVay v26.35.01-1 web components and Tailwind CSS 4.3.5. Open any screen and resize the window: under 600 px one pane shows, at 960 px the domain rail appears, at 1280 px the thread docks. URL options: ?theme=dark|high-contrast, ?os=macos|windows|linux|ios|android, ?density=compact, and on a phone-width window ?pane=list|main|thread.

ChatEmailChat stays inside one domain. Email crosses domains.
