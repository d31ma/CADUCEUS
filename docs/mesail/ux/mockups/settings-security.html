Profile and account

Password and 2-step sign-in: states

Mockup only. Each frame is one state. In the product the dialogs open from Profile and account, centred on wide screens and full screen on phones. 2-step sign-in is for example.com only.

A. The 2-step sign-in row

Shown in Account and sign-in. Buttons appear only when the state is known.

B. Change your password

One dialog. No repeat field: each password field has its own Show button.

C. Turn on 2-step sign-in

One dialog in 3 steps. Back keeps what was typed. There are no recovery codes.

D. Set up on a new phone

The same 3 steps as C. Step 1 also asks for a 2-step code.

E. Turn off 2-step sign-in

Needs the password and a code, so a borrowed, unlocked device cannot turn it off.
